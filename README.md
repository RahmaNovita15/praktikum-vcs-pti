# Praktikum Administrasi Digital
Repository ini dibuat untuk memenuhi kegiatan Praktikum 1 pada mata kuliah Administrasi Digital, Program Studi Pendidikan Teknologi Informasi.

## Deskripsi
Praktikum ini membahas penggunaan GitHub sebagai platform untuk menyimpan proyek, mengelola berkas, dan mencatat perubahan menggunakan Version Control System (VCS).

## Tujuan Praktikum
1. Memahami cara membuat repository di GitHub.
2. Mengenal fungsi README.md sebagai dokumentasi proyek.
3. Memahami proses commit untuk menyimpan perubahan.
4. Mengenal penggunaan GitHub dalam kolaborasi digital.
